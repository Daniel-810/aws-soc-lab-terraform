# ADR-006. 보안 소프트웨어를 배포판 패키지로 설치한다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-02 |
| 관련 | `NFR-07`, `SR-22`, `F11` |

---

## 맥락

원본은 웹 방화벽 구성 요소를 소스에서 빌드해 설치했다. 최소 사양 인스턴스에서 30분 이상 소요됐다.

## 결정

배포판 저장소의 패키지로 설치한다. 소스 컴파일을 사용하지 않는다.

## 근거

소스 컴파일의 대가가 빌드 시간만이 아니다.

| 문제 | 내용 |
|---|---|
| 보안 패치 미수신 | 패키지 관리자가 존재를 인식하지 못해 업데이트 대상에서 제외된다 |
| 취약점 스캔 누락 | 스캐너는 패키지 목록을 기준으로 판단하므로 **취약점 없음으로 오보고**된다 |
| 버전 미고정 | 원본은 버전 태그 없이 기본 분기를 받아왔다. 빌드 시점마다 다른 코드가 설치되며, 동작 중인 버전을 특정할 수 없어 취약점 대응이 불가능하다 |
| 패치 회피 유도 | 수동 빌드한 모듈이 특정 웹서버 버전에 묶여, **웹서버를 패치하면 모듈이 동작하지 않는다.** 결과적으로 패치를 피하게 된다 |

마지막 항목이 핵심이다. **보안 모듈을 넣으려는 선택이 그 아래 웹서버의 패치를 막는 결과**를 낳았다.

## 고려한 대안

**사전 이미지 빌드** — 부팅 시간이 가장 짧고 불변 인프라 개념을 실증한다. 다만 이미지 빌드 파이프라인을 별도로 관리해야 한다. 배포판 패키지가 제공되지 않을 경우의 대안으로 유지한다.

## 결과

- 배포판이 제공하는 버전으로 고정된다. 최신 기능을 즉시 쓸 수 없다.
- ⚠️ **해당 배포판에 패키지가 실제로 제공되는지 확인되지 않았다. Phase 7 착수 즉시 확인하고, 없을 경우 사전 이미지 방식으로 전환한다.**
- 비용 절감을 위해 채택한 기동/삭제 사이클이 **패치 관리에도 기여한다.** 매 기동 시 최신 패키지로 부팅되므로 불변 인프라의 이점을 얻는다.
