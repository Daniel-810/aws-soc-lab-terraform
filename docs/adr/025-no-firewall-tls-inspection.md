# ADR-025. 관리형 방화벽의 TLS 검사를 사용하지 않는다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-25 |
| 관련 | `FR-02`, `NFR-04`, `SR-24`, `T-11`, `ADR-008`, `ADR-017`, `ADR-022` |

---

## 맥락

Phase 8 측정에서 같은 요청을 평문(80)과 암호화(443) 경로로 보냈을 때, 관리형 방화벽은 평문 경로에서만 경보를 남겼고 암호화 경로에서는 한 건도 탐지하지 못했다. 방화벽이 TLS 종료 지점보다 앞에 있어 암호문만 보기 때문이다(`ADR-008`).

이는 제품의 기술 한계가 아니다. 관리형 방화벽은 두 가지 방식으로 암호화 트래픽을 다룰 수 있다.

- **복호화 없이 핸드셰이크 정보를 본다.** 접속하려는 도메인 이름(SNI)과 클라이언트 지문을 룰로 검사할 수 있다. 요청 내용은 보이지 않는다.
- **TLS 검사 구성으로 복호화한다.** 복호화된 평문에 기존 룰이 그대로 적용된다. 인바운드 검사에는 서버 인증서와 개인 키를, 아웃바운드 검사에는 인증 기관 인증서를 인증서 관리 서비스에 등록해야 한다.

## 결정

**관리형 방화벽의 TLS 검사(복호화)를 사용하지 않는다.** 암호화 구간의 L7 검사는 TLS를 종료하는 웹 방화벽이 맡는다.

## 근거

- **비용이 예산 요구사항을 넘는다.** 서울 리전 온디맨드 기준(2026-09-25, 요금 조회 API) 기본 엔드포인트는 시간당 $0.395이고, 고급 검사 엔드포인트는 시간당 $0.792다. 고급 검사가 기본 요금에 더해진다면 방화벽만 시간당 약 $1.19가 되어, 전체 기동 단가를 시간당 1,000원 이하로 요구하는 `NFR-04`를 넘는다(환율 1,400원 가정 시 약 1,800원). 월 예산으로 기동 가능한 시간은 약 70시간에서 약 28시간으로 줄어든다.
- **인바운드 검사는 개인 키를 외부 서비스에 맡겨야 한다.** 웹 방화벽 외부용 인증서의 개인 키를 인증서 관리 서비스에 등록해야 하며, 이를 Terraform으로 수행하면 키가 상태 파일을 거친다. `ADR-017`과 `SR-24`는 개인 키가 Terraform을 거치지 않도록 요구한다.
- **이 프로젝트가 측정하려는 차이가 사라진다.** 복호화를 켜면 방화벽도 웹 방화벽처럼 평문을 본다. 계층마다 볼 수 있는 범위가 다르다는 점(`T-11`)이 이 구성의 측정 대상이다.
- L7 검사를 TLS 종료 지점에서 수행하는 것은 복호화를 한 번만 하는 구성이다. 방화벽에서 복호화하면 웹 방화벽과 합쳐 같은 트래픽을 두 번 복호화하게 된다.

## 고려한 대안

**인바운드와 아웃바운드 모두 TLS 검사** — 모든 계층이 평문을 보므로 탐지 범위가 가장 넓다. 위의 비용, 개인 키 위탁, 비교축 소실 문제를 모두 진다.

**아웃바운드만 TLS 검사** — 서버 개인 키가 필요 없어 `ADR-017`과 충돌하지 않는다. 인스턴스가 방화벽의 인증 기관을 신뢰하도록 구성해야 하며, 엔드포인트 시간당 요금은 같아 `NFR-04`를 넘는다.

**복호화 없이 도메인 이름(SNI)으로 검사** — 추가 요금과 인증서가 필요 없다. 요청 내용은 볼 수 없으나 알려진 목적지로 나가는 암호화 통신은 차단할 수 있다. 이 결정과 충돌하지 않으며 별도로 적용할 수 있다.

## 결과

- **암호화 경로에서 방화벽의 탐지는 0으로 남는다.** 측정 결과에 이 구성의 결과임을 명시하고, 제품의 한계로 서술하지 않는다.
- 요금 조회 결과만으로는 고급 검사 요금이 기본 요금에 더해지는지 대체하는지, 그리고 이 요금 항목이 TLS 검사에만 해당하는지 확인하지 못했다. 요금 페이지로 확인한 뒤 이 문서를 갱신한다.
- 프로덕션에서 방화벽 수준의 복호화가 필요하다면 이 결정을 다시 검토한다. 판단 기준은 복호화 비용, 개인 키 보관 위치, 복호화 지점의 개수다.
