# ADR-010. VPC 대역으로 10.20.0.0/16을 사용한다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-02 |
| 관련 | `NFR-05` |

---

## 맥락

원본은 `10.0.0.0/16`을 사용했다. 재구성에서 유지할지 결정한다.

## 결정

`10.20.0.0/16`을 사용한다.

## 근거

- `10.0.0.0/16`·`192.168.0.0/16`·기본 VPC 대역은 **광범위하게 사용되는 대역**이다.
- VPC 피어링, 게이트웨이 연결, 온프레미스 VPN 구성 시 **대역이 겹치면 연결 자체가 불가능**하다.
- **IP 대역은 사후 변경이 사실상 불가능하다.** 전체 리소스를 재생성해야 한다.
- 실무에서는 조직 차원으로 대역을 관리하고 흔한 대역을 회피한다.

## 고려한 대안

**`10.0.0.0/16` 유지** — 원본과 동일해 매뉴얼 대조가 쉽다. 이 랩은 단일 계정이고 피어링·VPN 계획이 없어 충돌 위험이 실재하지 않는다.

## 결과

- 원본 매뉴얼과 대역이 달라 직접 대조 시 주의가 필요하다.
- 랩 환경에서는 실질적 이득이 없다. **관행을 따르는 것 자체가 목적**이며, 실제 조직 환경에서 동일한 판단이 필요하다는 점을 문서로 남긴다.
