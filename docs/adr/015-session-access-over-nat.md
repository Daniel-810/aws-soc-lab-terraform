# ADR-015. 세션 관리자 트래픽을 NAT 게이트웨이로 내보낸다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-04 |
| 관련 | `SR-01`, `SR-03`, `NFR-04`, `FR-10` |

---

## 맥락

애플리케이션 인스턴스는 프라이빗 서브넷에 있고 공인 IP를 갖지 않는다(`SR-03`). 동시에 `SR-01`이 모든 인스턴스에서 SSH 인바운드 규칙을 금지하므로, 관리 접근은 세션 관리 서비스로만 가능하다.

세션 관리 에이전트는 인스턴스에서 **밖으로 나가** 서비스 엔드포인트에 연결을 맺고, 그 통로로 명령을 수신한다. 인바운드 규칙이 필요 없는 이유가 이것이다. 따라서 결정해야 할 것은 접근 방식이 아니라 **에이전트의 아웃바운드 443이 어느 경로로 서비스에 도달하는가**이다.

경로는 두 가지뿐이다. NAT 게이트웨이를 거쳐 공용 인터넷으로 나가거나, VPC 인터페이스 엔드포인트를 만들어 AWS 내부망으로만 통신하거나.

## 결정

**NAT 게이트웨이를 경유한다.** VPC 인터페이스 엔드포인트를 생성하지 않는다.

## 근거

- NAT 게이트웨이는 `ADR-009`에 따라 이미 검사 계층 앞에 존재한다. **추가 고정비가 발생하지 않는다.**
- 인터페이스 엔드포인트는 세 개(`ssm`, `ssmmessages`, `ec2messages`)가 필요하고 각각 가용영역별로 시간당 과금된다. 이 환경은 up/down 사이클로 운영하므로(`ADR-005` 계열의 비용 전제) **상시 과금 리소스를 늘리지 않는 편이 `NFR-04`에 부합한다.**
- 세션 트래픽이 아웃바운드 검사 대상에 포함되는 것이 오히려 `FR-10`의 취지에 맞다. `FR-10`은 침해를 전제로 외부 통신을 관측하기 위한 요구사항인데, **관리 채널을 검사에서 제외하면 그 채널이 검사를 우회하는 경로가 된다.**

## 고려한 대안

**VPC 인터페이스 엔드포인트 3종** — 기술적으로 더 나은 선택이다. 트래픽이 VPC를 벗어나지 않고, 엔드포인트에 보안그룹이 붙으므로 `waf-sg`의 아웃바운드를 `0.0.0.0/0`이 아닌 **엔드포인트 보안그룹 참조로 좁힐 수 있다.** 인터넷 게이트웨이가 없는 VPC에서도 동작한다. 무엇보다 검사 계층을 경유하지 않으므로 **방화벽 정책을 잘못 구성해도 관리 접근이 유지된다.** 채택하지 않은 이유는 상시 과금 리소스가 세 개 늘어나는 것 하나뿐이며, 예산 제약이 없다면 이쪽이 옳다.

**베스천 호스트** — 퍼블릭 서브넷에 점프 서버를 두고 SSH로 경유하는 전통적 방식. 인스턴스가 한 대 더 필요하고 22번 포트를 열어야 하므로 `SR-01`과 `AC-07`(22번 인바운드 0건)에 정면으로 위배된다. 원본 환경의 결함 `F5`가 이 구성에서 비롯됐다. 검토 대상이 아니다.

## 결과

- **`waf-sg`의 아웃바운드 `0.0.0.0/0:443`을 좁힐 수 없다.** 세션 관리 서비스의 주소 대역이 안정적이지 않기 때문이다. 그 결과 같은 보안그룹의 `waf → app` 443 규칙은 넓은 규칙에 포함되어 **통신 제어 측면에서는 중복**이 된다. 해당 규칙은 의도를 드러내는 문서로서 유지하되, "앱으로 가는 통신을 제한했다"고 서술하지 않는다.
- **Phase 8에서 관리 접근이 끊길 수 있다.** 현재 `nat-rt`의 기본 경로는 임시로 인터넷 게이트웨이를 향하지만, 검사 계층이 만들어지면 방화벽으로 교체된다. 그 시점부터 세션 트래픽이 방화벽을 통과하므로, **정책에서 443 아웃바운드를 허용하지 않으면 인스턴스에 접근할 수단이 사라진다.** 라우팅을 되돌리는 것 외에는 복구 방법이 없다.
  - **대응 절차**: Phase 8 착수 시 방화벽 정책에 443 아웃바운드 허용을 **먼저** 반영하고, 라우팅 타깃 교체는 그 다음에 수행한다. 교체 직후 세션 접속을 검증한다.
- 방화벽·흐름 로그에 관리 채널 트래픽이 섞인다. 탐지 룰을 조정할 때(`SR-12`) 이 트래픽을 정상 통신으로 분류해야 한다.
- **프로덕션 환경이라면 인터페이스 엔드포인트를 사용한다.** 관리 평면 트래픽을 인터넷으로 내보내지 않는 것이 원칙이고, 비용은 그 원칙을 뒤집을 사유가 되지 못한다. 이 결정은 랩의 예산 제약에 한정된다.
