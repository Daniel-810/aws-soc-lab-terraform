# ADR-007. 만료되는 임시 자격 증명을 사용한다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-02 |
| 관련 | `SR-05`, `T-31` |

---

## 맥락

원본 매뉴얼은 IAM 사용자 생성으로 끝난다. 장기 액세스 키를 사용하는 방식이다.

## 결정

관리 콘솔과 API 접근에 **만료되는 임시 자격 증명**을 사용한다. 장기 액세스 키를 생성하지 않는다.

## 근거

- 장기 액세스 키는 만료되지 않으므로 **유출 시 무기한 유효**하다. 유출 시점을 인지하기도 어렵다.
- 보안 점검 도구에서 우선 지적 항목이다.
- `T-31`(운영자 자격 증명 탈취)의 피해 범위를 시간적으로 제한한다.

## 고려한 대안

**IAM 사용자 + 다중 인증** — 설정이 간단하다. 그러나 액세스 키가 만료되지 않는 문제는 그대로 남는다.

## 결과

- 초기 설정에 시간이 소요된다.
- 자격 증명이 주기적으로 만료되므로 갱신 절차가 필요하다.
- 인스턴스 역할의 자격 증명도 임시이지만, **탈취되면 인스턴스 밖에서도 만료 전까지 사용 가능하다**(`T-15`). 이는 별도 통제(`SR-06` 최소 권한, `SR-23` 감사 기록)로 대응한다.
