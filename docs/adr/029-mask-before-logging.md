# ADR-029. 민감값은 웹 방화벽이 기록하기 전에 가린다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 |
| 일자 | 2026-09-25 |
| 관련 | `SR-10`, `SR-16`, `FR-05`, `ADR-018`, `ADR-028` |

---

## 맥락

웹 방화벽 감사 로그에는 요청 본문이 들어간다. Phase 7에서 정탐과 오탐을 판단하려고 넣었다. 그래서 로그인 요청의 비밀번호가 그대로 기록된다. 로그가 인스턴스 안에만 있을 때는 노출 범위가 작았지만, Phase 10에서 CloudWatch로 보내면 로그를 조회할 수 있는 모든 주체에게 노출된다.

가리는 지점은 세 곳이 있다. 로그를 만드는 곳, 수집 경로, 수집한 뒤의 저장소다.

## 결정

**웹 방화벽(ModSecurity)이 감사 로그를 기록하기 전에 가린다.**

- 자격 증명을 본문에 싣는 경로(로그인, 가입, 비밀번호 재설정)는 감사 기록을 남기되 요청 본문을 빼고 기록한다.
- 자격 증명을 질의 문자열에 싣는 경로(비밀번호 변경)는 감사 기록을 남기지 않는다. 검사와 차단은 그대로 한다.
- 인자 단위 가림은 쓰지 않는다. 이 엔진이 지원하지 않는다(아래 결과).

## 근거

- **실무 원칙은 가능한 한 앞에서 가리는 것이다.** 기록하기 전에 가리면 민감값이 디스크에도, 수집 경로에도, 저장소에도 남지 않는다. 저장소에서 가리는 방식은 원본이 한 번은 들어간 뒤라 보조 수단이다.
- **자격 증명 경로에서 본문을 빼는 것은 인코딩과 무관하게 확실하다.** 인자 단위 가림은 엔진이 본문을 인자로 해석했을 때만 동작한다. 형식이 다르거나 해석에 실패한 본문은 원문 그대로 남을 수 있다.
- **질의 문자열은 모든 기록의 요청 줄에 들어간다.** 본문을 빼는 것으로는 가려지지 않으므로, 그 경로는 기록하지 않는 것 외에 방법이 없다.
- **정탐과 오탐 판단 근거는 대부분 유지된다.** 본문이 빠지는 것은 자격 증명 경로뿐이다. 그 경로에서도 요청 헤더와 규칙 메시지는 남는다.
- 추가 비용이 없다.

## 고려한 대안

**CloudWatch 데이터 보호 정책** — 수집한 뒤 저장소에서 가린다. 원본이 AWS 안에 남고, 가림을 해제하는 권한이 있으면 볼 수 있다. 스캔 용량당 요금이 붙는다. 이 환경에서는 보조 수단으로도 두지 않았다.

**요청 본문 기록 전체 중단** — 가장 확실하다. 모든 경로에서 오탐 판단 근거가 사라진다.

**수집 경로에서 치환** — 수집기에서 정규식으로 바꾼다. 이 환경의 에이전트는 줄 단위 포함과 제외만 지원해 치환할 수 없다.

## 결과

- **인자 단위 가림(`sanitiseMatched`)은 이 엔진에서 쓸 수 없었다.** 첫 배포에서 웹 서버 설정 검사가 `Action: SanitiseMatched is not yet supported`로 실패했다(libmodsecurity 3.0.12). 처음 결정은 경로별 본문 제외와 인자 단위 가림을 함께 쓰는 것이었고, 가림을 뺐다.
- **배포로 확인한 결과 (2026-09-25).** 비밀번호 자리에 표식 문자열을 넣고 공격 패턴을 섞어 기록되게 만든 요청을 보냈다.
  - 로그인: 기록은 남고(탐지 룰 5개) 본문이 없다. 표식은 디스크와 CloudWatch 어디에도 없다.
  - 비밀번호 변경: 기록이 없다. 요청은 차단됐다.
  - **목록에 없는 경로**(`/api/Feedbacks`)의 `secretToken` 인자: **표식이 디스크와 CloudWatch에 그대로 남았다.**
- **보호 범위는 목록에 넣은 경로뿐이다.** 이 앱에서 자격 증명이 오가는 경로는 모두 목록에 넣었지만, 새 경로가 생기거나 다른 경로로 비밀값이 들어오면 가려지지 않는다. 이 한계를 없애려면 수집 경로에서 치환하는 수집기(`ADR-028`의 대안으로 검토한 서드파티 수집기)나 저장소의 데이터 보호 정책이 필요하다.
- 새로운 자격 증명 경로가 생기면 경로 목록에 추가해야 한다. 목록 방식의 한계다.
- 측정 도구가 JSON 본문 위치에 쓰는 로그인 경로도 본문이 빠진다. 측정은 요청 헤더의 번호표와 규칙 메시지만 읽으므로 영향이 없다.
