모두 비용이 없고 랩이 아니라 계정 전체에 해당해 상시 환경(`envs/audit`)과 `bootstrap`에 두었다.

## 4. 오탐

- **웹 방화벽 사용자 데이터의 「비밀번호로 보이는 값」.** Prowler가 압축된 사용자 데이터를 풀어 검사했다. 걸린 두 줄은 비밀번호를 기록에서 빼려고 둔 ModSecurity 규칙의 경로 이름(`/rest/user/login`, `change-password`)이었다. 비밀값은 없다.

## 5. 후속 확인

- ~~**EC2 역할의 혼동된 대리인 방지 조건 (3건).**~~ ✅ 2026-09-26 해결. 세 역할 신뢰 정책에 `aws:SourceAccount` 조건을 넣고 배포했다. 세 인스턴스 모두 자격증명을 받아 세션 관리자, 시크릿 조회, 로그 전송이 동작했고, 이 점검만 다시 돌려 세 역할 모두 통과를 확인했다(`ADR-036`).

## 6. 계정 운영자가 판단할 것 (코드 범위 밖)

- 루트 계정 사용 기록이 있다. 일상 작업은 루트가 아닌 주체로 한다.
- 루트와 IAM 사용자의 MFA가 가상 장치다. 하드웨어 키는 구매가 필요하다.
- 탐지와 사후 분석 서비스(GuardDuty, Security Hub, Config, Inspector, Macie)가 꺼져 있다. 유료이며 이 프로젝트의 범위 밖이다.
- 쓰지 않는 서비스(Bedrock, SageMaker, Organizations, 지원 요금제)에 관한 점검은 해당 없음으로 본다.
