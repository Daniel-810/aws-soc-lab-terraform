# Payloads

`gotestwaf/` holds test cases copied unchanged from
[wallarm/gotestwaf](https://github.com/wallarm/gotestwaf) at tag `v0.5.8`,
used under the MIT License (`gotestwaf/LICENSE`).

- `owasp/` — attack payloads grouped by class
- `false-pos/` — benign text used to measure false positives

Only the payload lists are used. The GoTestWAF tool itself is not.
